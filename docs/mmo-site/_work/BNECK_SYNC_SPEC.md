# P1 — 기존 11장 정정 3건

노션 전수 대조 결과 **어긋난 곳은 셋뿐이다.** 나머지 8장은 값·표기 전부 일치(재확인 불필요).

### ① ⑦ IOCP 워커 12→4 — "3회 편차"의 왼쪽 값

`scene.js` s:7 의 `ab` 세 번째 줄.

- 지금 : `["3회 편차","48~185","0.2 ms","재현성",1]`
- 노션 : 4차 표 12×2 비고 **"회차마다 튐 (왕복 102 → 185 → 140ms)"** · 상세 토글도 `102 / 185 / 140`
- 고칠 값 : `48~185` → **`102~185`**
- 근거 : 왼쪽 값 `48`은 현재 노션 어디에도 없다. 12×2의 왕복 3회는 102·185·140이다.

### ② ⑩ 송신 워커 K2 → K3 — 소켓 호출 K2 값

두 곳을 같이 고친다.

- `ab` 네 번째 줄 : `["소켓 호출","99k","122k /s","+23%",-1]` → 왼쪽 **`100k`**
- `LOAD` 표 `[10, 923, 93.4, null, 99000, 122000]` → **`100000`**
- 노션 : 측정부하 "소켓 호출 **100k**/s (변경 후 122k)" · 3절 표 K2 **100k** · K3 122k
- 근거 : 사이트 주석은 "3절 표에는 K2 99k"라고 적었는데, 현재 노션은 두 곳 다 100k다(그 사이 노션이 손질됨).
- ⚠ 소스 주석도 같이 손봐야 한다 — `/* ⑩ 부하 줄은 소켓 호출을 99k~122k 범위로 적었지만... */`

### ③ ⑪ 게임스레드 코어 격리 — 게임루프 CPU 절대값 복원

- 지금 : `["게임루프 CPU","","−5%","절대값은 노션 미기재",1]`
- 노션 : 3절 ① 표 **"게임루프 CPU (코어) | 0.531 → 0.503 (−5%)"** — 절대값 쌍이 지금은 있다
- 고칠 값 : `["게임루프 CPU","0.531","0.503 코어","−5%",1]`
- ⚠ 위의 긴 주석(`노션은 이 칸을 Δ 한 값으로만 적는다 ... 지어낸 값으로 보인다`)은 **전제가 뒤집혔으므로
  갈아써야 한다.** 새 주석 취지 = "한때 노션이 Δ만 적어 이 칸을 비웠으나, 이후 노션이 절대값 쌍을
  실었다(2026-08-18 대조). CEIL_cc5000 CSV의 0.5234→0.5076(−3.0%)와는 다른데, 노션 쪽이 3rep 중앙값이다."
