# 수치 1:1 대조 로그 (2026-08-18)

앞선 전수 대조는 한 번에 몰아서 했다. 이번은 **카드 4장씩 네 틱**으로 나눠,
카드 한 장의 **모든 필드**(`cond` · `bm` 4값 · `am` 4값 · `ab` 전 행 4열 · `ld` 5값 · `hint` · `abh`)를
노션 원문과 1:1로 맞춘다. 매 틱마다 해당 노션 페이지를 **다시 당겨서** 본다.

**⚠ 무엇이 문제였나** — 노션은 송신 메시지를 K 별로 나누지 않았다(K 가 바꾸는 건 분배뿐이라 통제 지표로 묶어
"약 1,000만/s" 로만 적었다). 그런데 사이트는 **1,001만 → 1,005만이라는, 노션에도 없고 근거 주석도 없는 값**을
들고 있었다. 다른 카드(⑦·⑧·⑪)는 노션에 없는 값을 채울 때 반드시 런 이름과 산식을 주석에 남겼는데 여기만 없었다.

**어떻게 잡았나** — 계기판 아랫줄의 곱(**송신 메시지 × 평균 패킷 = 송신량**)으로 검산했더니 어긋났다.
`1,001만 × 93.4 B = 935 MB/s` 인데 노션 송신량은 **938** 이다.

**고친 값** — 같은 표의 송신량·평균 패킷에서 역산했다.
`938 ÷ 93.4 = 1,004만` · `940 ÷ 93.4 = 1,006만` → 곱을 되돌리면 **937.7 / 939.6** 으로 노션 938 / 940 과 맞는다.
산식과 경위를 소스 주석에 남겼다.
