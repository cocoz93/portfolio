계단·덩어리·이름표를 끌어서 배치합니다. 그림 코드는 parts/safe-scene.js 하나를 페이지와 같이 씁니다 — 여기서 본 것이 곧 페이지에서 보는 것입니다.
반영하는 순서 ① Export 로 복사 → ② parts/safe-scene.js 의 var SCENE={…}; 를 통째로 붙여넣기 → ③ build.ps1 -NoSync 실행 (조각을 index.html 로 합치는 단계라, 빼면 페이지가 그대로입니다).
