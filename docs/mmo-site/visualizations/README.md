## 로컬 페이지 가독성 조정

`1-3 핵심 최적화`의 1번은 제목·설명·N회→1회 효과를 그림 밖의 설명 영역에 표시한다. 고정 화면 폭 대신 실제 작업 영역의 남은 공간을 사용한다. 그림 카드 1000px·사이 간격 28px·설명 최소 폭 260px을 함께 담을 수 있으면 설명이 오른쪽의 남은 폭을 모두 차지하고, 담을 수 없을 때만 아래로 줄바꿈한다. 2~5번은 기존 상단 설명을 유지한다. 데스크톱 목차는 축소 전의 폭 220px·글자 16px·버튼 높이 약 52px로 복원하고, 넓은 화면에서는 왼쪽 바깥 여백 44px·오른쪽 바깥 여백 32px로 두어 본문 제목이 상단 1-3보다 약 20px 왼쪽에서 시작한다. 1200px 미만 화면에서는 이 추가 바깥 여백을 해제한다. 본문 안쪽 좌우 여백은 20px이며, 1번은 본문 카드 폭을 최대 1000px로 줄이고 도식이 내부 가용 폭을 채우게 한다. 카드 안의 추가 좌우 빈 공간은 없으며 기존 안쪽 여백 20px만 유지한다. 데스크톱 카드 폭 1000px에서 그림 폭은 958px, 높이는 508px다. 2~5번의 그림 표시 폭은 기존 최대 1000px·중앙 배치를 유지한다. 좁은 데스크톱·태블릿의 본문 내용 폭 670~963px 구간은 90% 배율로 기존 가로 비교 배치를 유지하고, 모바일에서는 별도 좌우 여백을 두지 않는다. 재생 버튼과 단계 설명은 현재 표시 배율을 보정해 기존 크기를 유지한다. 원본과 독립 재생 파일은 이 배율 조정으로 수정하지 않는다. 좁은 화면의 목차는 한 줄 가로 스크롤이며, 선택한 항목이 보이도록 위치를 맞춘다.
3번은 글자 밝기를 유지하고 수신자 간격을 줄였다. 4번은 넓은 화면에서 SendQ를 2×2로 배치한다.
1번은 변경 전·후 행의 왼쪽에 정사각형 이동 지도를 하나씩 배치하고, 각 지도에서 해당 행의 Msg로 배선이 직접 이어진다. 데스크톱 도식 높이는 548px에서 508px로, 행 간격은 248px에서 226px로 줄였다. 지도·링버퍼·캐릭터 크기를 조금 줄이고 Msg 카드 높이 76과 제목·좌표 글자 14는 유지했다. 추가했던 커널 블록·연결선·점등 효과는 제거했다. 원래의 작은 커널 경계 표시와 송신 출구는 유지한다. 좁은 화면의 세로 배치와 애니메이션 단계·호출 순서는 유지한다.
좁은 화면에서는 각 비교 영역을 지도→Msg→SendQ 순서로 배치한다. 두 캐릭터가 같은 경로를 동시에 움직이고 전·후의 좌표 전달·Msg 생성·SendQ 적재를 동시에 재생한다. 변경 전은 매번 즉시 송신하고 변경 후는 누적 후 틱 끝에 한 번 송신한다.
5번은 서버 float 좌표를 공통 입력으로 한 번만 표시하고, 변경 전·후에는 좌표 변환과 Msg 기록을 비교한다.
1번의 설명 영역은 48px·800 굵기의 두 줄 제목 `WSASend` / `호출 묶기`, 14px `Send Coalescing`, 40px `N회 → 1회`, 16px 설명 한 문장과 작은 `그림은 N=4 예시` 표기로 구성한다. 오른쪽 설명 영역에는 고정 최대 폭을 두지 않으며 본문의 읽기 폭은 최대 360px로 제한한다. 제목은 설명 영역의 실제 폭에 따라 36~48px로 연속 조절하고, 640px 이하 화면에서는 36px로 표시한다. 그림 카드 폭과 도식 크기는 이 줄바꿈 조정으로 변경하지 않는다. 설명은 별도 테두리 없이 표시하고, 같은 제목 노드를 이동하므로 중복 제목은 만들지 않는다. 기존 상단 설명이 빠져 그림이 약 99px 위로 올라간다. 애니메이션은 N=4 예시이며 실제 호출 카운터는 0~4회와 0~1회로 동작한다. 그림의 도구 모음에는 재생·구도 보기 버튼과 재생 중인 단계 설명만 남긴다.
1번은 사용자 요청에 따라 순차 비교에서 동시 비교로 재생 순서를 변경했다. 공통 입력은 네 번이고 송신 호출은 변경 전 4회·변경 후 1회다. 2~5번의 Msg·Ref 생명주기, Digest 구성·적재, 양자화 값과 재생 순서는 유지한다.
각 폴더의 기존 `qa/review.json`은 조정 전 기록이다. 그때의 구도 보존 검사를 현재 레이아웃의 통과 근거로 사용하지 않는다.

## 유지할 의미

- 대상: 면접관과 장기 복습용 본인. 네이비 PCB와 선명한 블루 톤을 유지한다.
- 3번은 한 Msg를 세 번 재사용하고 마지막에 반환한다. Ref 예시는 1→4→3→2→1→0이며 SendQ에는 사본이 남는다.
- 4번은 수신 섹터별 Digest를 같은 섹터 주민에게 재사용한다. 위 세 섹터의 주민은 2/1/1명, SendQ는 4개다.
- 5번은 서버 float을 유지하고 ×512·반올림 후 uint16로 기록한다. 이름·값·4B/2B가 함께 바뀌며 네 칸이 두 칸으로 줄어든다. Msg 이동은 한 번이고, 원래 슬롯에 블록이 다시 생기지 않는다. 반올림 오차 안내가 있다.
